# eat-burn

Телеграм-бот для подсчёта калорий с дневной нормой. Пишешь, что съела или сколько сожгла, а бот показывает, сколько осталось на сегодня. Родственник [debit&credit](https://github.com/curcs/debit-credit), только вместо денег калории.

Всё работает локально. Фразы и фото разбирает локальная модель через [Ollama](https://ollama.com). Калорийность модель не придумывает, бот берёт её из баз продуктов.

## Как писать боту

| Сообщение | Что будет |
|---|---|
| `450 рацион обед` | Еда числом, записывается сразу. Подходит для готовых рационов и ресторанной цифры, которую подсказала LLM |
| `-200 бег` | Тренировка: 200 ккал возвращаются в остаток дня |
| `овсянка 60г, банан, ложка мёда` | Модель разбирает фразу на продукты и граммы, бот считает по базе и присылает разбор с кнопками ✅ ✏️ ❌ |
| фото тарелки | То же самое. Подпись к фото работает как подсказка: «гречка 200г» |
| скриншот карточки блюда из сервиса рационов (BeFit и похожие) | Бот читает ккал, БЖУ и граммы через tesseract. Если цифры сходятся (4·Б + 9·Ж + 4·У ≈ ккал), записывает сразу |
| фото бумажного меню на день | Бот читает все блюда с граммами и БЖУ и добавляет их в справочник. Галочками можно отметить уже съеденное, остальное записывать потом через `/f`. Если калории не читаются (например, обведены ручкой), бот считает их из БЖУ |
| скриншот списка заказов | Бот находит все блюда и даёт отметить галочками, что съедено. Уже записанное за сегодня отмечено не будет |
| фото штрихкода | Бот ищет продукт в Open Food Facts и спрашивает, сколько съела: вся упаковка, половина или граммами. Telegram сжимает фото, поэтому снимай штрихкод крупно; если не читается, отправь фото файлом («Файл» в меню скрепки), так оно придёт без сжатия |
| фото этикетки «пищевая ценность» | Если штрихкода нет в базе: бот читает ккал и БЖУ на 100 г. Подпись к фото вроде `батончик 40` сразу даёт название и граммы |
| `часы 412` | Активные ккал за день с Apple Watch. В остаток идёт то, что сверх обычного движения (см. ниже) |
| `вода`, `стакан воды`, `2 стакана воды`, `бутылка воды`, `вода 500`, `-вода` | Стакан = 200 мл, кружка 300, бутылка 500; своё количество или убрать последний. После записи — кнопки типичных порций. Чай идёт в воду на 90%, кофе на 80% (объём из записи, иначе чашка 250 мл, эспрессо 30) |
| `болит голова`, `давление`, `слабость` | Запись самочувствия. Можно и вместе с едой: «съела творог, голова болит» |
| 🎙 голосовое | Расшифровывает локальный whisper (модель small) с подсказкой из твоего справочника, дальше как обычный текст |

Блюда со скриншотов сразу попадают в справочник. В следующий раз хватит написать название.

Всё, что записано с цифрой (`450 цезарь жан-жак`), бот запоминает как блюдо на порцию. В следующий раз хватит `цезарь жан-жак`: бот предложит 450 ккал «как в прошлый раз». Подтверждаешь ✅ или присылаешь другое число, тогда запомнится новая цифра. Список блюд — `/dishes`, удалить блюдо — `/dish_del название`.

Граммы пиши с «г»: `творог 150г`. Просто `150 творог` бот поймёт как 150 ккал.

Команды:

- `/today` — сегодня и остаток; у каждой записи кнопки ✏️ (поменять ккал) и 🗑 (удалить, с «↩️ вернуть»), внизу 💧 +250 мл
- `/week` — неделя по дням, средняя и график: съедено против «можно с активностью», вес отдельной панелью
- `/patterns` — чем дни с головной болью или давлением отличаются от обычных: напитки, время первой еды, вода, углеводы, белок. Нужно ~2 недели отметок самочувствия; вечером бот спрашивает кнопками 👍 🤕 😵 😩. Это наблюдения для разговора с врачом, а не диагноз
- `/tdee` — реальный расход по весу и записанной еде; `/goal adapt` ставит норму по нему
- `/undo` — удалить последнюю запись
- `/weight 57.5` — записать вес, норма пересчитается
- `/goal 1300` — задать свою норму; `/goal auto` снова считает по формуле
- `/food чак-чак 450` — добавить в личный справочник ккал на 100 г
- `/f лимонад` — найти блюдо в справочнике и записать одним нажатием; `/f` без слов покажет то, что записываешь чаще всего
- `/dishes` — все запомненные блюда, `/dish_del название` — удалить
- `/remind` — напоминания: раз в неделю утром про вес (по умолчанию в среду, можно ответить просто числом), днём про еду, если давно ничего не записано; `/remind off` выключает
- `/file` — табличка xlsx с листами «Журнал», «Дни» и «Вес»

Каждый вечер в 22:00 бот присылает итог дня. По воскресеньям в 21:00 приходит сводка за неделю с табличкой.

## Как считается

- **Норма.** Считается по формуле Миффлина — Сан Жеора с коэффициентом 1,2 (сидячий образ жизни, тренировки пишутся отдельно) и дефицитом 15%, округляется до 50. Например, для 30 лет, 165 см и 60 кг выходит 1350 ккал.
- **Остаток** = норма − съедено + тренировки.
- **Где ищется продукт:** сначала личный справочник, потом USDA FoodData Central (офлайн, `data/usda.db`), потом Open Food Facts. Если продукта нигде нет, бот спросит ккал на 100 г и запомнит ответ.
- **Часы за день.** Apple Watch насчитывает активные калории и в сидячий день, обычно 150–300, а это движение уже заложено в норму. Поэтому в остаток идёт только то, что сверх `ACTIVE_BASELINE` (по умолчанию 200). Если в тот же день записаны тренировки вручную, засчитывается большее, а не сумма: прогулка с часов уже внутри их дневной цифры.
- **Реальный расход.** Нужны хотя бы два взвешивания с разницей в 14 дней или больше, а еда должна быть записана минимум в 70% дней между ними. Бот берёт тренд веса по всем взвешиваниям (1 кг ≈ 7 700 ккал) и среднее съеденное: расход = съедено + похудение × 7 700. Так видно, насколько формула и часы расходятся с реальностью. Норму сам не меняет, это делает `/goal adapt`.
- **Новый день начинается в 4 утра**: перекус после полуночи считается во вчерашний день.
- **Хранение.** Данные лежат в `data/eatburn.db` (SQLite), xlsx собирается по запросу.

## Часы автоматически: быстрая команда на iPhone

Чтобы не писать `часы 412` вручную, сделай автоматизацию в приложении «Команды»:

1. «Автоматизация» → «+» → «Время суток», например 21:30, ежедневно, «Запускать сразу».
2. Действие «Найти образцы здоровья»: тип «Активная энергия», дата начала «сегодня».
3. «Вычислить статистику» → «Сумма» по найденным образцам, затем «Округлить число».
4. «Текст»: `часы ` и результат округления.
5. Отправь текст боту: действием Telegram «Отправить сообщение», выбрав чат с ботом. Если чат с ботом там не выбирается, используй «Открыть URL» `https://t.me/ИМЯ_БОТА?text=` + текст: откроется чат с готовым сообщением, останется нажать «отправить».

Цифра за день перезаписывается, так что команду можно запускать и несколько раз.

## Доступ из Claude (MCP)

`mcp_server.py` — локальный MCP-сервер, только для чтения: сводки за день и неделю, записи, итоги по дням, вес, справочник, реальный расход. Подключить к Claude Code:

```bash
claude mcp add eat-burn -s user -- "$PWD/venv/bin/python" "$PWD/mcp_server.py"
```

После этого можно спрашивать Claude «как прошла неделя по питанию?», и он будет смотреть прямо в базу бота.

## Как запустить

Нужны Mac (лучше на Apple Silicon, от 16 ГБ памяти) и Python 3.10 или новее.

**1. Поставь Ollama и модели.** Скачай [Ollama](https://ollama.com/download) и запусти её. Потом загрузи две модели, вместе около 8 ГБ:

```bash
ollama pull qwen2.5:7b && ollama pull gemma3:4b
```

Для скриншотов рационов нужен ещё tesseract с русским языком. Его удобно поставить через [Homebrew](https://brew.sh):

```bash
brew install tesseract tesseract-lang
```

Для голосовых нужен ffmpeg (`brew install ffmpeg`). Модель whisper small (~480 МБ) скачается сама при первом голосовом.

**2. Заведи своего бота.** В Телеграме открой [@BotFather](https://t.me/BotFather), отправь `/newbot` и придумай имя. В ответ придёт токен — длинная строка вида `123456789:AAH...`.

**3. Узнай свой telegram id.** Напиши [@userinfobot](https://t.me/userinfobot), он ответит числом. Бот будет слушаться только этого id.

**4. Скачай код, поставь зависимости и базу продуктов.**

```bash
git clone https://github.com/curcs/eat-burn.git
cd eat-burn
python3 -m venv venv
./venv/bin/pip install -r requirements.txt
./venv/bin/python tools/load_usda.py
```

Последняя команда один раз скачивает базу USDA, около 10 МБ.

**5. Впиши ключи и профиль.**

```bash
cp config.example.py config.py
```

Открой `config.py` и впиши токен, свой id, рост, год рождения и вес. По ним бот посчитает дневную норму. `config.py` уже в `.gitignore`, токен никому не показывай.

**6. Запусти.**

```bash
./venv/bin/python bot.py
```

Напиши боту `/start`, он ответит нормой и подсказкой.

**Автозапуск.** Чтобы бот работал в фоне и сам поднимался после перезагрузки, запусти из папки проекта:

```bash
sed "s|__DIR__|$PWD|g" com.eatburn.bot.plist > ~/Library/LaunchAgents/com.eatburn.bot.plist
launchctl load ~/Library/LaunchAgents/com.eatburn.bot.plist
```

Бот работает, пока Mac не спит. Сообщения, отправленные, пока он спал, бот обработает после пробуждения.

Тесты: `./venv/bin/pytest -q`
